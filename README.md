# GB KIRANA — Customer Information Website

A responsive, information-only website for GB Kirana in Madhurawada.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colors, responsive styling and animations
- `script.js` — mobile navigation and current footer year
- `assets/` — folder reserved for shop images and other local assets

## Preview locally
Open `index.html` in a web browser.

## Publish with GitHub and Vercel
1. Create a GitHub repository named `gb-kirana`.
2. Upload the contents of this folder (not the ZIP file itself).
3. Import that repository into Vercel and deploy with the default settings.

## Before publishing
- Confirm the exact shop address in Madhurawada.
- Add and verify the shop's public contact number if desired.
- Confirm that the opening hours are correct.
- The map link currently searches for "GB Kirana Madhurawada"; verify the correct map pin before sharing the site.

This starter website does not include product listings, prices, online ordering, payments, or a database.
